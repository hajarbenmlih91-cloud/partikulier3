# Partikulier user stories / guides utilisateurs

FR — Ce dossier contient deux pages HTML autonomes, sans dépendance externe :

- `user-stories.html` : version détaillée pour les équipes produit et développement, avec récits utilisateur, critères d’acceptation et liens vers les diagrammes PNG.
- `guide-utilisateurs-simple.html` : version simple et non technique pour propriétaires, acheteurs et partenaires métier.

Ouvrez les fichiers dans un navigateur. Utilisez le bouton de langue FR/EN, puis **Imprimer → Enregistrer en PDF** pour exporter la langue affichée.

EN — This folder contains two self-contained HTML pages with no external dependency:

- `user-stories.html`: detailed version for product and development teams, with user stories, acceptance criteria and links to PNG diagrams.
- `guide-utilisateurs-simple.html`: simple non-technical version for owners, buyers and business stakeholders.

Open the files in a browser. Use the FR/EN language button, then **Print → Save as PDF** to export the currently displayed language.
